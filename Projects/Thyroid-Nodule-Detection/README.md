# Thyroid Nodule Detection Using Deep Learning

A deep learning research project focused on detecting thyroid nodules from ultrasound images using a hybrid CNN-VGG19 approach with attention.

## Technologies
- Python
- Deep Learning
- CNN
- VGG19
- Attention

## Project
Thyroid Nodule Detection Using Deep Learning
