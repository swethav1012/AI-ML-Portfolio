# Recyclable Waste Classification Using Deep Learning

A deep learning project for classifying recyclable waste using the VGG16 architecture.

## Technologies
- Python
- VGG16
- CNN
- Deep Learning

## Project Files
- `App.py` — Application interface
- `VggModel.py` — VGG16 model implementation

## Project Focus
Automated image-based waste classification to support efficient waste management.
